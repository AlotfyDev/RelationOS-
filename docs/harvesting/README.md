# Place PDF specifications here

## Supported Formats
- SysML v2 specifications
- UML 2.5.1 specifications  
- OWL 2 specifications
- OSLC Core specifications
- Other MBSE-related standards

## File Naming Convention
- Use descriptive names: `SysML-v2-2023-09-01.pdf`
- Avoid spaces, use hyphens
- Include version and date when available

## Processing Notes
- Files larger than 500MB will be skipped
- Only text-based PDFs are supported (not scanned images)
- Processing is logged to console and harvest.log
